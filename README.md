# Noion — AI 耳コピ & 伴奏生成ツール

音源から MIDI を自動採譜し、SoundFont で高品質な伴奏トラックを合成するツール。

## 歌ってみた向け制作ガイド

Noion の出力は「歌ってみた」用伴奏として最適化されています。

### なぜ -16 LUFS？

一般的な音楽配信は -14 LUFS (YouTube/Spotify 基準) ですが、Noion は **-16 LUFS** で出力します。

- ボーカルを重ねると合計ラウドネスが上がるため、伴奏に 2dB のヘッドルームが必要
- -16 LUFS の伴奏 + ボーカルで合計 -14 LUFS 前後に着地
- True Peak も -1.5 dBTP に設定し、ボーカル合成後の ISP (Inter-Sample Peak) を防止

### DAW での使い方

1. Noion で生成した伴奏 (WAV/MP3) を DAW にインポート
2. ボーカルトラックを追加 (フェーダーは 0dB スタート)
3. マスターバスが -14 LUFS / -1.0 dBTP に収まるようボーカルフェーダーを調整
4. 伴奏のフェーダーは基本的に触らなくて OK

### ステレオ配置

伴奏のパート配置はヘッドフォンで広がりのあるステレオイメージになるよう設計されています。

| パート | 位置 | 備考 |
|--------|------|------|
| メロディ (ピアノ) | やや左 (pan=62) | ボーカルの邪魔にならない位置 |
| コード (ストリングス) | LR ワイド | stereo_widen 保持 |
| ベース | センター (pan=64) | モノラル、低域を安定化 |
| パッド | LR 最大幅 | コーラス + Haas で広がり |
| 装飾 (グロッケン) | 右寄り (pan=90) | アクセント的に配置 |
| サブメロディ | やや左 (pan=50) | メインメロディと対位置 |
| ドラム | 周波数帯別配置 | kick=C, snare=やや左, hihat=右, cymbal=右 |

ボーカルはセンターに配置されるため、伴奏がセンターを避けることでマスキングを低減し、各パートの分離感を向上させます。
